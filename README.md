# CodeAlpha Social Media Application

CodeAlpha Full Stack Development Internship — Task 2.

## Features

- User registration and login
- User profiles and bio
- Create posts
- View posts
- Like/unlike posts
- Add comments
- Follow/unfollow users
- SQLite database for users, posts, comments, likes and followers

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- SQLite (`node:sqlite`)
- JWT
- bcryptjs

## Run Locally

```bash
npm install
npm start
```

Open:

http://localhost:3000

## Database

The SQLite database is created automatically at:

`data/social.db`

The database file is ignored by Git.
